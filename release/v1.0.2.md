Fixes missing offline images and improves installed-game content setup.

- Corrects embedded resource addresses so generic category and enchantment icons load without game files. Images are loaded immediately and frozen for background/UI use.
- Adds a masked AES key field to the Game Files dialog. Entered keys are used only for the current session and are not saved to disk, the registry, or the environment. MCD_PAK_AES_KEY remains supported.
- Prompts for game-content setup when no key is configured and explains missing or rejected keys instead of suggesting an application update.
- Loads unencrypted PAKs without a key, tries supplied keys regardless of archive GUID, and rejects incomplete archive loading.

**Game images:** encrypted installed-game assets still require the AES key matching your game version; no game key is bundled. Enter the key in the Game Files dialog. Choose No game content for offline save editing with generic icons.

Windows regression checks decode the bundled icons, verify frozen images across threads, and cover session-key handling and normal PAK loading. The release workflow reruns Windows Debug/Release tests and x64/x86 native package smoke checks before packaging.

Download the ZIP matching your Windows architecture, extract the complete directory, and install the matching serviced **.NET 10 Desktop Runtime**. Binaries are framework-dependent and are not Authenticode-signed.

Finalized ZIPs have GitHub SLSA build-provenance attestations and downloadable Sigstore bundles. The immutable release attestation binds the tag, source commit, and all attached assets. SHA256SUMS and complete corresponding source are included.

```sh
gh release verify v1.0.2 --repo compunaut/MCDSaveEdit
gh release verify-asset v1.0.2 MCDSaveEdit-v1.0.2-win-x64.zip --repo compunaut/MCDSaveEdit
gh attestation verify MCDSaveEdit-v1.0.2-win-x64.zip --repo compunaut/MCDSaveEdit
```

Real installed-game compatibility beyond available fixtures, manual gameplay, additional console variants, and Steam Deck/Wine remain unverified. Avoid concurrent save edits and retain backups. Earlier immutable releases remain unchanged.
