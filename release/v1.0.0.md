First release of the maintained personal fork of CutFlame/MCDSaveEdit.

- .NET 10 WPF build with locked dependencies and offline save editing.
- Removed automatic telemetry, remote configuration, and obsolete ZIP/embedding components.
- Recoverable save writes with unique backups and stale-save checks.
- Hardened JSON, PAK, decompression, texture buffers, and crypto stream ownership.
- Windows Debug/Release tests, x64/x86 native provenance checks and actual package smoke tests.

Download the ZIP matching your Windows architecture, extract the whole directory, and install the matching serviced **.NET 10 Desktop Runtime**. Binaries are framework-dependent and are not Authenticode-signed.

The ZIPs carry GitHub SLSA build-provenance attestations. The immutable GitHub release also carries a release attestation binding the tag, source commit, and attached assets. `SHA256SUMS` and downloadable Sigstore bundles accompany the binaries and complete corresponding source archive. License notices are retained in every binary ZIP and in source.

```sh
gh release verify v1.0.0 --repo compunaut/MCDSaveEdit
gh release verify-asset v1.0.0 MCDSaveEdit-v1.0.0-win-x64.zip --repo compunaut/MCDSaveEdit
gh attestation verify MCDSaveEdit-v1.0.0-win-x64.zip --repo compunaut/MCDSaveEdit
```

Manual in-game, additional console variants, and Steam Deck/Wine compatibility remain unverified. Use disposable save copies first and retain backups. Attestations establish provenance and integrity, not a guarantee of bug-free or universally compatible software.
