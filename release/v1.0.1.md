Patch release addressing all six findings from the November 2 fork audit.

- Preserve stale-save protection when changing the interface language, preventing an older in-memory profile from silently overwriting external changes.
- Validate package allocation counts before allocation and bound property reads, seeks, nesting, and parsing progress.
- Preserve modification metadata and invested enchantment points when duplicating items.
- Propagate image preload failures to the startup error handler and limited-feature fallback.
- Restrict the native apphost provenance exemption to the exact application executable path.

Regression coverage includes external-save changes across a UI reload, complete item metadata round trips, bounded malformed-package cases, and nested executable provenance rejection. The release workflow reruns Windows Debug/Release tests and actual x64/x86 native package smoke checks before packaging the validated binaries.

Download the ZIP matching your Windows architecture, extract the complete directory, and install the matching serviced **.NET 10 Desktop Runtime**. Binaries are framework-dependent and are not Authenticode-signed. This patch supersedes v1.0.0; the immutable v1.0.0 assets remain unchanged.

The finalized ZIPs have GitHub SLSA build-provenance attestations and downloadable Sigstore bundles. GitHub's immutable release attestation binds the release tag, source commit, and all attached assets. SHA256SUMS and a complete matching source archive are included.

```sh
gh release verify v1.0.1 --repo compunaut/MCDSaveEdit
gh release verify-asset v1.0.1 MCDSaveEdit-v1.0.1-win-x64.zip --repo compunaut/MCDSaveEdit
gh attestation verify MCDSaveEdit-v1.0.1-win-x64.zip --repo compunaut/MCDSaveEdit
```

Manual gameplay, additional console variants, and Steam Deck/Wine compatibility remain unverified. The snapshot check is not an OS-level compare-and-swap; avoid concurrent edits by the game and editor and retain backups. Attestations establish provenance and asset integrity, not universal compatibility or absence of defects.
